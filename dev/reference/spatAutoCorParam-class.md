# Spatial autocorrelation parameter classes

Parameter classes for spatial autocorrelation of features over a spatial
network: \`moranParam\` (Moran's I), \`gearyParam\` (Geary's C) and
\`binSpectParam\` (binSpect, a join count on binarized features). All
extend the virtual \`spatAutoCorParam\`. Build them with
\[spatAutoCorParam()\].
