# read_crossSection

read a cross section object from a giotto object

## Usage

``` r
read_crossSection(
  gobject,
  spat_unit = NULL,
  name = NULL,
  spatial_network_name = NULL
)
```

## Arguments

- gobject:

  gobject

- spat_unit:

  spatial unit

- name:

  name

- spatial_network_name:

  spatial_network_name

## Value

crossSectionObjects
