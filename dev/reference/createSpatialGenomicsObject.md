# Create Spatial Genomics Giotto Object

Given the path to a Spatial Genomics data directory, creates a Giotto
object.

## Usage

``` r
createSpatialGenomicsObject(sg_dir = NULL, instructions = NULL)
```

## Arguments

- sg_dir:

  full path to the exported Spatial Genomics directory

- instructions:

  new instructions (e.g. result from createGiottoInstructions)

## Value

giotto object
