# create_mesh_grid_lines

create mesh grid lines for cross section

## Usage

``` r
create_mesh_grid_lines(
  cell_subset_projection_locations,
  extend_ratio,
  mesh_grid_n
)
```

## Arguments

- cell_subset_projection_locations:

  cell_subset_projection_locations

- extend_ratio:

  extend_ratio

- mesh_grid_n:

  mesh_grid_n

## Value

mesh grid lines
