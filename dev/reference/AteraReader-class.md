# Atera reader

In-memory reader behind
[`importAtera()`](https://giottosuite.com/dev/reference/importAtera.md)
without a `backend`. Inherits the `XeniumReader` implementation. Atera
v1 output (zarr) is read with a `backend`; see
[`importAtera()`](https://giottosuite.com/dev/reference/importAtera.md).
