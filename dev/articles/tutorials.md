# Browse tutorials

Tutorials for each step of a Giotto analysis, from building the object
to spatial patterns and integration with other tools. Each one runs on a
small example dataset, but the methods apply to any platform. For
end-to-end examples on a specific technology, see [Browse
datasets](https://giottosuite.com/dev/articles/datasets.md); to set
Giotto up, see
[Installation](https://giottosuite.com/dev/articles/installation.md).
